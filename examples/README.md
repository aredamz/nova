# Examples

Run the commands from the repository root, and create the output folder first
(`mkdir -p out`).

| Folder | Description | Command |
|---|---|---|
| `product-ad/` | A 1920x1080 advertisement, 15 s. Data binding (`data.json`), SVG, an image with a slow zoom, shadows, springs, "drawn" lines and a closing scene. | `nova render examples/product-ad/template.json --data examples/product-ad/data.json -o out/product-ad.mp4` |
| `shorts/` | A vertical 1080x1920 video, 10 s, with changing captions and a progress bar. It uses assets from the other example folders, so the asset root is `examples/`. | `nova render examples/shorts/template.json --assets-root examples -o out/shorts.mp4` |
| `kes01/` | A complete episode, "Kes #01 — Jam Emas Dalam Gelap" (1080x1920, 123 s, without voice), ported from a Remotion episode: 11 scenes, characters with expressions, blinking and mouth shapes, karaoke subtitles, suspect cards, polaroids and rain. The template is generated by a script. | `python3 examples/kes01/generate.py && nova render examples/kes01/template.json -o out/kes01.mp4` |
| `remotion-bake/` | A small Remotion project (1280x720, 4 s) rendered through the frame bake: its React code runs in Node.js and NOVA draws the result. Requires `npm install` in `tools/remotion-bake` and in `examples/remotion-bake`. | `node tools/remotion-bake/render.mjs --project examples/remotion-bake --target examples/remotion-bake/target.ts --fonts examples/shared/fonts --out out/hello.mp4` |
| `shared/fonts/` | Noto Sans Regular and Bold (SIL Open Font License 1.1). | |

To review a whole video at a glance before a full render:

```bash
nova sheet examples/shorts/template.json --assets-root examples --count 8 --columns 4 -o out/shorts-sheet.png
```
